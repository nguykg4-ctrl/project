# Changelog

All notable changes to the `com.screenworking.collaboration` package will be documented in this file.

## [1.0.0] - 2026-07-27

### Added

- Initial clean-room release of `[screen working]` real-time Unity Editor collaboration tool.
- Stable identity sidecar component (`ScreenWorkingIdentity`).
- Typed serialized value representation (`SerializedValue`).
- Echo suppression context manager (`ScreenWorkingSyncScope`).
- Change tracker for GameObject creation, transform edits, hierarchy reparenting, and component property changes.
- Deterministic Lamport CRDT conflict resolution engine.
- ASP.NET Core 8 WebSocket backend server with EF Core database support.
- In-process multi-client simulator test suite.
